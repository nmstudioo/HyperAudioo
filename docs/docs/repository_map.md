# HyperAudio · Repository Map

An annotated map of every tracked file in the HyperAudio repository.

## Directory Layout

```text
HyperAudioo/
├── README.md · index.html · ATTRIBUTION.md · SHA256SUMS
├── LICENSE · LICENSE.md · LICENSE-MIT · LICENSE-CC-BY-SA-4.0
├── robots.txt · site.webmanifest · sitemap.xml
├── Redmi_12/   Speaker assets and docs
├── edx_pro/    IEM assets and docs
├── docs/       reference, method and test documents
├── data/       raw measurements, targets, method note
├── addons/     optional IRS files and reference presets
└── assets/     site code, images, fonts, harness reports
```

Root Files

File Purpose
README.md Main project overview and quick start guide.
