    Deployment guide How to load into RootlessJamesDSP

    Chain order: DDC → Convolver (IRS) → EEL2 Liveprog → Crossfeed → ViperClarity. Load each of the three files into its respective slot. Set the RootlessJamesDSP sample rate to match the impulse (48 kHz or 44.1 kHz). The .eel script's limiter is fixed at −1.5 dBFS, leaving headroom for post-EEL stages.

    The ™ symbol in the filename may be sanitized to _ by MIUI's MediaStore on save. Files remain fully functional; only the display name is affected.

    The first "Download all" click may prompt Chrome for permission to allow multiple downloads. Accept to receive all three files.

    V4.0 changes PDR · soft knee · ADAA · derived preamp

    PDR limiter — dual-envelope gain reduction: fast τ=10 ms for transients, slow τ=150 ms for sustained loudness, blended by linear gain reduction. Eliminates bass pumping on kick-heavy content.

    Soft-knee de-esser — parabolic knee around threshold: x²/(4·thr). 1st-derivative continuous gain reduction, no snap on sibilance onset.

    ADAA tape saturator — antiderivative anti-aliasing on x − x³/3: F(x) = x²/2 − x⁴/12. Suppresses odd-order alias products without oversampling. Retains the 16 kHz post-LPF for higher-order fold-back.

    Derived preamp — JS bisection on the FFT-audited peak response so the headroom margin lands at exactly 0.50 dB. Recovered ~4.8 dB on IEM, ~2.6 dB on Speaker.

    Known limitations What V4.0 does and does not guarantee

    EEL2 has no true-peak / inter-sample-peak limiter builtin. The −1.5 dBFS ceiling absorbs typical program material overshoot; pathological full-scale content may still overshoot at DAC reconstruction by < 0.5 dB.

    PDR blending uses linear gain reduction, not dB domain — a deliberate CPU tradeoff. dB-domain blending is ~1.4× more accurate but costs 2 log/pow per sample.

    ADAA suppresses only 1st-order odd-harmonic aliasing. Above tapeAmt100 > 70%, the 16 kHz post-LPF is doing the heavy lifting. Both are kept active.
