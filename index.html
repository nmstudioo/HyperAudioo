03

Quick start

  1. Pick the right guide first. The IEM guide uses the three-file chain. The Speaker guide uses standalone Liveprog PEQ and excludes its VDC and IRS files.
  2. Set the host to 48 kHz and verify the running rate. Set convolver preamp to 0 dB for the IEM chain.
  3. Turn off other processing: extra EQ, bass enhancement and OEM sound effects.
  4. Load in order: DDC (.vdc), then Convolver (.irs), then Liveprog (.eel).
  5. Start at low volume and confirm the profile and processing mode.

Evidence boundary. Offline checks use a source-built JamesDSP VM on x86_64. They are not native ARM, RootlessJamesDSP app, device or listening tests. Numerically qualified does not mean device validated.

Known limitations

  • Reproducibility. iem_build.py, generate_irs.py and the source inputs are not included, so the IRS cannot be regenerated from this repository alone.
  • Speaker IRS provenance. The measurement setup is not documented. Any microphone response in the source measurement is also in the filter.
  • IEM voicing. It has no measurement behind it and is a design choice.
  • Spatial processing. The IEM surround feature is crossfeed plus width, not HRTF virtualisation.
  • ARM. EEL tests ran on x86_64. The v5 processing-mode selector has not been VM- or device-tested.
  • Limiter scope. Sample-peak limiting is not true-peak limiting or driver-excursion protection.
  • Sample rate. The IRS assets are 48 kHz only. Another host rate changes timing and frequency behaviour.
08

Raw and target curves

Each correction is fitted against a target curve, in dB relative to 1 kHz. Both targets are custom, built offline, and not published standards. Listening results outrank the curves.

  • Trust broad shape over narrow detail, especially on a single-position speaker measurement.
  • Never correct an artifact such as a coupler resonance or a room effect.
  • Never boost where the device has no output. The speaker has almost nothing below 100 Hz.

Documentation

Deployment guideLoad into RootlessJamesDSP

Chain: DDC (identity) → Convolver (IRS) → EEL2 → Output. Set the host sample rate to 48 kHz and load each file into its slot.

Tonal correction lives only in the IRS. Never load the same EQ in both the VDC and the convolver: it applies twice.
